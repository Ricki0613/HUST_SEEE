# 华中科技大学电气学院专业课程资料分享

## 简介

本仓库用于收集和分享华中科技大学电气学院的专业课程资料。

我是华中科技大学电气学院 2024 级学生，仓库中收集的课程资料与整理的备考笔记主要对应 **2024 级同学学习相关课程的时期**。不同年级的课程安排、教学内容和考试要求可能有所变化，使用时请结合实际情况参考。

目前仓库收录了**电机学**相关资料，包括教材、题解、课件、往年题，以及我使用 Notion 整理的课程笔记和期末复习笔记。其中电机学下册部分基于华中科技大学出版社《电机学（第四版）》（辜承林、陈乔夫、熊永前主编），涵盖异步电机与同步电机。

如果你也有本仓库尚未收录的课程资料或学习笔记，欢迎提交 Pull Request，一起完善这个资料库。

希望这些资料能够帮助大家学习和复习，也欢迎有收获的同学为仓库点一个 Star！
