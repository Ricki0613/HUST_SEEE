# 华中科技大学电气学院专业课程资料分享

## 简介

本仓库用于收集和分享华中科技大学电气学院的专业课程资料，包括课程课件、教材与题解、往年题、学习笔记和备考资料等。我会陆续整理并上传其他课程的相关资料，希望能为大家的学习与复习提供一些帮助。

伟大的冰岩作坊开发的 [1037.wiki](https://1037.wiki/) 收录了大量学习资料，伟大的学数、学电 QQ 群中也有许多群友分享的资料，方便大家在群文件中按课程查找所需内容。感谢冰岩作坊和所有无私分享的同学，shout out to 1037.wiki 和学数、学电 QQ 群！

这些平台为大家查找资料提供了很大帮助，但由于上传时使用的关键词可能不同，在 1037.wiki 上有时难以快速、一次性地搜索到某门课程的所有已有文件；QQ群文件中的资料也比较分散，收录未必全面。因此，我希望把自己收集和整理的电气专业课程资料集中到这个仓库，方便同学们按课程查找，也欢迎大家结合 1037.wiki 和 QQ 群中的资料一起使用。

我是华中科技大学电气学院 2024 级学生，仓库中收集的资料与整理的备考笔记主要对应 **2024 级同学学习相关课程的时期**。不同年级的课程安排、教学内容和考试要求可能有所变化，使用时请结合实际情况参考。

如果你也有本仓库尚未收录的课程资料或学习笔记，欢迎提交 Pull Request，一起完善这个资料库。

希望这些资料能够帮助大家学习和复习，也欢迎有收获的同学为仓库点一个 Star！
