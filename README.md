# 华中科技大学电气学院专业课程资料分享

## 简介

本仓库用于收集和分享华中科技大学电气学院的专业课程资料，包括课程课件、教材与题解、往年题、学习笔记和备考资料等。我会陆续整理并上传其他课程的相关资料，希望能为大家的学习与复习提供一些帮助。

我是华中科技大学电气学院 2024 级学生，仓库中收集的资料与整理的备考笔记主要对应 **2024 级同学学习相关课程的时期**。不同年级的课程安排、教学内容和考试要求可能有所变化，使用时请结合实际情况参考。

伟大的冰岩作坊开发的 [1037.wiki](https://1037.wiki/) 中有大量学习资料，shout out to 1037.wiki！由于同学们上传资料时使用的关键词可能不同，有时较难快速、一次性地搜索到某门课程的所有已有文件。我希望通过这个仓库将电气专业的课程资料整理在一起，为大家查找和使用提供一些便利。

如果你也有本仓库尚未收录的课程资料或学习笔记，欢迎提交 Pull Request，一起完善这个资料库。

希望这些资料能够帮助大家学习和复习，也欢迎有收获的同学为仓库点一个 Star！
