# 实验三 仪器操作指南

面向 STM32F407 开发板 + 示波器 + 直流稳压电源 + 函数信号发生器的 A/D 实验。
三个任务的接线、读数、故障排查都在本文，按顺序做即可。

---

## 0. 开始之前的四条硬规矩

| 规矩 | 说明 |
|---|---|
| 必须共地 | 每台仪器的地（黑夹/屏蔽层）都要和开发板 GND 连在一起，否则读数乱跳或直接读到 0 |
| 先接地，后接信号 | 接线：地 → 信号；拆线：信号 → 地。带电插拔信号线容易打坏 ADC 引脚 |
| 不超 3.3 V | 片内 ADC 是单极性，输入 0~3.3 V。信号源的"偏置 + 幅度"之和必须落在 0~3.3 V 内 |
| 先设参数，后开输出 | 电源、信号源都是设好参数再按 Output。改参数前先关输出，避免电压冲击 |

万用表只用**直流电压档**测电压，不要用电流档去并接电源输出（会短路）。

## 1. 直流稳压电源

### 1.1 认识面板

| 部件 | 作用 |
|---|---|
| CH1 / CH2 键 | 选择要调节的通道，本实验只用一路 |
| VOLTAGE 旋钮 | 调输出电压；多数机型按一下可在粗调/细调间切换 |
| CURRENT 旋钮 | 调**限流值**，不是调电流大小 |
| CV / CC 指示灯 | CV 恒压（正常）、CC 恒流（负载过流或短路，要马上关输出） |
| Output / On-Off 键 | 输出开关，灯亮才有电压输出 |

### 1.2 设置 1.00 V 的标准步骤

1. 开机，按 CH1 选中通道。
2. **先设限流**：按 CURRENT 键，把限流调到 50 mA 左右（旋钮逆时针到底再慢慢加）。
   限流是保护，不是工作点；负载正常时电源工作在 CV 模式。
3. 按 VOLTAGE，把电压调到 1.00 V（先粗调到 1.0，再细调）。
4. 万用表直流电压档接红黑输出端，微调电压直到万用表显示 1.00 V，
   **记下实际值**（例如 0.998 V 或 1.003 V），这就是后面写进程序 `DMM_MV`、写进报告的数。
5. 关闭输出 → 红夹接 PA5（板上丝印 STM_ADC），黑夹接开发板 GND → 再打开输出。
6. 确认 CV 灯常亮、电压不跌落。一旦跳到 CC 或电压明显下降，立即关输出查线。

### 1.3 与开发板连接的两个要点

- **必须拔掉 P12 跳线帽**。PA5 同时接 TPAD 触摸检测，跳线帽不拔会分压，读数会偏低或乱跳。
- 直流电源只提供被测电压，**不要用它给开发板供电**，板子照常用 USB 供电。

### 1.4 记录（任务 1 用）

| 项目 | 数值 |
|---|---|
| 万用表实测输入电压 | ______ V（填进 `DMM_MV`，单位 mV） |
| 8 位平均码值 `adc8_avg` | ______（理论约 78） |
| 8 位换算电压 `v8` | ______ V |
| 12 位平均码值 `adc12_avg` | ______（理论约 1241） |
| 12 位换算电压 `v12` | ______ V |

## 2. 函数信号发生器

### 2.1 认识面板

| 部件 | 作用 |
|---|---|
| Sine / Square / Ramp 键 | 选波形，本实验用 Sine |
| Frequency 键 | 设频率，注意单位 Hz / kHz |
| Amplitude / Level 键 | 设幅度，机型可能用 Vpp、Vrms 或 High/Low 电平 |
| Offset 键 | 设直流偏置（有的机型写作 DC Offset、DC Level） |
| Output / On 键 | 输出开关 |
| 输出阻抗设置 | 50 Ω 或 High-Z，**最容易设错的一项**，见 2.2 第 5 条 |
| 数字键 + Enter | 输入数值后必须按单位键或 Enter 才生效 |

### 2.2 设置 50 Hz / Vp-p 2 V / 偏置 1.0 V

1. 按 Sine 选正弦波。
2. Frequency 设为 `50` `Hz`。
3. 幅度按机型二选一：
   - 菜单是 **Vpp**：直接设 `2.000 Vpp`；
   - 菜单是 **Vrms**：正弦波设 `0.707 Vrms`（= 2 Vpp / 2√2）；
   - 菜单是 **High/Low Level**：设 High = `2.0 V`、Low = `0.0 V`，
     此时偏置自动为 1.0 V，幅度自动为 2 Vpp，可跳过第 4 步。
4. Offset 设为 `+1.0 V`（正偏置，波形整体抬到 0 V 以上）。
5. **输出阻抗**：接示波器或开发板（都是高阻 1 MΩ 负载）时，菜单必须设成 **High-Z**。
   若误设为 50 Ω，实际输出幅度会接近设定值的 2 倍，出现"设 2 V 测到 4 V"的假象。
6. 按 Output 打开输出，然后立刻用示波器确认（见 2.3）。

### 2.3 用示波器确认后再接开发板

- 探头用 **DC 耦合**，垂直 0.5 V/div，时基 5 ms/div，触发源 CH1、上升沿、Auto。
- 正确波形：**最低点贴 0 V 格线，最高点在第 4 格**（0.5 V/div 时 4 格 = 2 V），
  一格一格数过去就是 0 V → 2 V，说明偏置 1.0 V、峰峰 2 V。
- 常见不符与处理：
  - 峰峰是 4 V：输出阻抗设成了 50 Ω；
  - 峰峰是 1.4 V：幅度菜单用了 Vrms，实际设成了 0.707 Vpp；
  - 波形整体下移、底部被削平：偏置是负值或设置了负偏置。

### 2.4 接开发板

- 信号输出（红）→ **PA4（板上丝印 STM_DAC）**，地（黑）→ 开发板 GND。
- PA4 同时连在 OLED/CAMERA 接口上，**本实验不要插 OLED 屏或摄像头模块**。
- 接上板后示波器可以继续并在信号点观察，确认波形没有被板子拉变形（不应明显变小或失真）。

## 3. 数字示波器

### 3.1 探头准备（每次都做）

1. 探头拨到 **×10** 档，示波器通道菜单里探头比也设 **10X**（两边必须一致，否则读数差 10 倍）。
2. 把探头钩到示波器面板的**补偿信号输出**（1 kHz 方波），调探头上的小电容，
   直到方波**平顶、直角**，不过冲也不圆角。换探头、换通道都要重新校一次。

### 3.2 快速出波形的顺序

1. 开机，CH1 菜单：耦合 **DC**、探头 **10X**、带宽限制关、反相关。
2. **垂直档位 VOLTS/DIV**：先 1 V/div，再按波形大小调到 3~6 格高。
3. **时基 SEC/DIV**：50 Hz 信号用 5 ms/div，屏上能看到 2~5 个周期。
4. **触发**：边沿触发、源 CH1、上升沿、模式 **Auto**；
   旋转 Level 旋钮把触发电平调到波形中部（约 1 V 处），波形才会稳定不左右跑。
5. 用垂直 Position 把 0 V 参考线放到屏幕下部格线，用水平 Position 把波形居中。
6. AUTO 键只用来第一次找波形；找到后立刻改手动设置，否则示波器可能自动改变档位导致误读。

### 3.3 读直流偏置和峰峰值（本实验最关键）

三种方法任选，推荐前两种：

| 方法 | 操作 | 结果 |
|---|---|---|
| 自动测量 | Measure → 源 CH1 → 选 峰峰值 Vpp、最大值 Vmax、最小值 Vmin、平均值 Vavg、频率 | 屏幕直接显示数值 |
| 光标 | Cursor → 电压光标，上下各放一条到波峰、波谷 | Vpp = 两条光标电压差 |
| 数格 | Vpp = 垂直格数 × VOLTS/DIV | 粗读，注意探头倍率已由示波器换算 |

判读要点：

- 只有 **DC 耦合**才能同时看出偏置和峰峰值。切到 AC 耦合后波形被重新居中，偏置信息丢失。
- 50 Hz、Vp-p 2 V、偏置 1.0 V 的正常画面：底部 0 V、顶部 2 V，Vmax≈2.0 V、Vmin≈0.0 V、
  Vavg≈1.0 V、频率 50.0 Hz。
- 记录时 Vpp 取三位有效数字（如 2.02 V），并注明是示波器读数，不要抄成信号源的设定值。

### 3.4 在开发板端测量

- 探头地夹接**开发板 GND**（尽量用短地弹簧，减少干扰和振铃）。
- 用 Run/Stop 冻结波形再读数；需要截图时按 Save/Print。
- 记录：Vpp、Vmax、Vmin、Vavg、频率、周期。

## 4. 三个任务的完整操作流程

### 任务 1：8 位与 12 位分辨率比较

1. 直流电源设 1.00 V，万用表确认，记录实际值。
2. 关输出 → 接 PA5 与 GND → 拔 P12 → 开输出。
3. 烧写 `Lab3_Task1`，串口助手 115200 观察。
4. 检查点：8 位码值约 78（范围 77~79），12 位码值约 1241；`v8`、`v12` 都应在 1.00 V 附近。
5. 读到 0 或 4095：查共地、P12、引脚是否接错。读数波动大：查限流是否变成 CC。

### 任务 2：50 Hz 正弦波峰峰值

1. 信号源设 50 Hz、Vpp 2 V、偏置 1.0 V、输出阻抗 High-Z。
2. 示波器 DC 耦合确认波形在 0~2 V。
3. 关输出 → 接 PA4 与 GND → 开输出 → 再确认波形。
4. 烧写 `Lab3_Task2`，串口看 `vpp_1k`、`vpp_10k`。
5. 检查点：1 kHz 读数约 1.97~2.00 V（每周期 20 点，最多偏小 1~2%）；
   10 kHz 读数约 2.00 V（每周期 200 点，误差可忽略）。
6. 两路都不正常时先怀疑信号源输出阻抗和偏置设置，而不是程序。

### 任务 3：双 ADC 采样 + LCD 显示

1. 同一条 GND 上同时接：直流 1.00 V → PA5，正弦波 → PA4。
2. 烧写 `Lab3_Task3`。
3. 检查点：LCD 上 DC 显示约 `1.00 V`、Vpp 显示约 `2.00 V`。
4. LCD 白屏/花屏先查液晶排线和 `lcd.c` 的驱动配置，不要误判为 ADC 问题。
5. 两路互相干扰（一路正常一路乱）：检查两个信号源的地是否都接到开发板 GND。

## 5. 常见故障速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 串口读数恒为 0 | 没接信号、没共地、P12 没拔 | 重接信号与地，拔 P12 |
| 串口读数恒为 4095 | 输入超过 3.3 V，或引脚被外部拉高 | 立刻断电检查接线与偏置 |
| 信号源设 2 V，示波器测到 4 V | 输出阻抗设成 50 Ω 接了高阻负载 | 改为 High-Z |
| 波形底部被削平、变方 | 偏置太大，低于 0 V 被钳位 | 减小偏置或幅度 |
| 示波器一条直线 | 触发源/触发电平不对、时基太慢 | 触发改 Auto、CH1、电平调中间 |
| 读数差 10 倍 | 探头 1X 但菜单设 10X（或反之） | 两边统一 |
| 串口乱码 | 波特率不是 115200，或 TX/RX 接反 | 重设串口助手、交换数据线 |
| 波形左右晃动不停 | 触发模式是 Normal 而电平未对上 | 用 Auto，调 Level |
| 电源一开就跳 CC | 短路、红黑夹碰线、接反 | 关输出，重新接线 |

---

## 6. 关机顺序

1. 关信号源、直流电源的**输出**；
2. 拆信号线（红）；
3. 拆地线（黑）；
4. 关仪器电源；
5. 断开开发板 USB，收好探头（拔探头前先松开钩子，不要拽线）。
